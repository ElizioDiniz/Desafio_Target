# Desafio Técnico

## 1. Comissão de Vendedores
Desenvolver um programa que leia os registros de vendas de um arquivo JSON e calcule a comissão de cada vendedor conforme as regras:

1 - Vendas abaixo de R$100,00 não gera comissão;

2 - Vendas abaixo de R$500,00 gera 1% de comissão;

3 - Venda a partir de R$500,00 gera 5% de comissão;


## 2. Controle de Estoque
Desenvolver um programa para registrar entradas e saídas de produtos, retornando ao final da movimentação a quantide final do estoque do produto
movimentado;

## 3. Cálculo de Juros
Desenvolver um programa que receba um valor e uma data de vencimento e calcule os juros até a data atual, considerando uma taxa de 2,5% ao dia;
